# VIVA ENGINE — OUT OF SCOPE
**Status:** STRICT (Do NOT touch these areas)

1.  **Lovable Base UI Code:** The frontend codebase in `frontend/src/` was largely generated by Lovable (from the `grade-my-voice` repo). Do NOT attempt to deeply refactor the Tailwind layout, CSS architecture, or core base components unless there is a critical integration bug. Our goal is to wire the UI to the backend, not redesign the UI.
2.  **OS-Level Binary Management:** Agents should NEVER attempt to write custom scripts to download, extract, or manage system-level binaries (like `poppler` or `ffmpeg`) for Windows/Mac within the application code. If a library requires heavy binaries, find a pure-Python or strictly ML-model-based alternative (e.g., Docling instead of Poppler).
3.  **Custom NLP/ML Model Training:** We do not train models. We exclusively use pre-trained APIs (OpenAI, Gemini) or pre-trained local weights (Docling, faster-whisper). Do not write PyTorch/Tensorflow training loops.
4.  **Custom Spaced Retrieval Math:** Do not modify the math behind the spaced repetition algorithm. Rely strictly on the `sm-2` package. Your job is managing the database state around cards, not calculating intervals.
5.  **Force Pushing to Main:** You are strictly forbidden from executing `git push -f` or pushing directly to `main`. Always work in `phase-*` branches.
